Flexbox

Kelola tata letak, penyelarasan, dan ukuran kolom grid, navigasi, komponen, dan lainnya dengan rangkaian lengkap utilitas flexbox responsif.

Enable Flex Behaviors

Terapkan utilitas display untuk membuat wadah flexbox dan mengubah elemen anak langsung menjadi item flex.

I'm a flexbox container!
I'm an inline flexbox container!
<div class="d-flex p-2">I'm a flexbox container!</div>
<div class="d-inline-flex p-2">I'm an inline flexbox container!</div>
