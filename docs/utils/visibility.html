Visibility

Kontrol visibilitas elemen, tanpa mengubah tampilan, dengan utilitas visibilitas.

Overview

Atur visibility elemen dengan kelas utilitas visibilitas kami. Kelas-kelas ini tidak mengubah nilai display sama sekali dan tidak memengaruhi tata letak – elemen .invisible masih memakan ruang di halaman.

...
...
<div class="visible">...</div>
<div class="invisible">...</div>

Contoh

Visible
Invisible (takes space)
Visible

Bandingkan dengan display: none (menggunakan .d-none):

Visible
Hidden (no space)
Visible
