Background Color

Mirip dengan kelas teks kontekstual, atur latar belakang elemen ke kelas kontekstual apa pun. Utilitas latar belakang tidak mengatur color, jadi dalam beberapa kasus Anda mungkin ingin menggunakan .text-* utilitas.

Sass

Utilitas background dihasilkan dari peta Sass $theme-colors dan $colors.

// sass/_variables.scss

$theme-colors: (
  "primary":    $primary,
  "secondary":  $secondary,
  // ...
);
