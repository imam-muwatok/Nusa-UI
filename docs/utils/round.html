Rounded

Utilitas untuk mengubah radius border elemen dengan berbagai ukuran.

Ukuran (Sizes)

Gunakan kelas .rounded-* untuk mengubah kelengkungan sudut elemen. Tersedia ukuran dari xs hingga xxl.

0
.rounded-0
XS
.rounded-xs
SM
.rounded-sm
Default
.rounded
LG
.rounded-lg
XL
.rounded-xl
XXL
.rounded-xxl

Bentuk Lain

Gunakan .rounded-circle untuk membuat lingkaran sempurna (jika lebar dan tinggi sama) atau .rounded-pill untuk bentuk kapsul.

Circle
Pill
<div class="rounded-circle">...</div>
<div class="rounded-pill">...</div>

Responsive

Anda dapat mengubah radius border berdasarkan ukuran layar menggunakan breakpoint infix (sm, md, lg, xl, xxl).

Responsive
.rounded-0 .rounded-md-circle
Toggle
.rounded-circle .rounded-lg-0
