Grid (Utilities)

Gunakan utilitas grid CSS untuk membuat tata letak grid yang kuat dan fleksibel.

Display Grid

Buat container grid dengan .d-grid atau .d-inline-grid. Ini menerapkan display: grid atau display: inline-grid ke elemen.

Grid item 1
Grid item 2
Grid item 3
Grid item 4
<div class="d-grid gap-3" style="grid-template-columns: 1fr 1fr;">
  <div>Grid item 1</div>
  <div>Grid item 2</div>
  <div>Grid item 3</div>
  <div>Grid item 4</div>
</div>

Gap

Gunakan utilitas gap untuk mengontrol jarak antar item grid (dan flex). Kelas .gap-0 hingga .gap-5 tersedia.

<div class="d-grid gap-2 d-md-block">
  <button class="nusa-btn nusa-btn-primary" type="button">Button</button>
  <button class="nusa-btn nusa-btn-primary" type="button">Button</button>
</div>
