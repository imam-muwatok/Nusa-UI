Float

Ubah float pada elemen apa pun, di breakpoint apa pun, menggunakan utilitas float responsif kami.

Overview

Kelas utilitas ini mengapungkan elemen ke kiri atau kanan, atau menonaktifkan pengapungan, berdasarkan ukuran viewport saat ini menggunakan properti CSS float. !important disertakan untuk menghindari masalah spesifisitas.

  • .float-start untuk mengapungkan elemen ke kiri (start).
  • .float-end untuk mengapungkan elemen ke kanan (end).
  • .float-none untuk menonaktifkan pengapungan.

Responsive

Variasi responsif juga tersedia untuk setiap nilai float.

  • .float-sm-start
  • .float-md-end
  • .float-lg-none
  • dan seterusnya...
