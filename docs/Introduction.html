Dokumentasi Nusa UI

Panduan lengkap dan contoh penggunaan komponen Nusa UI untuk membangun antarmuka web yang modern dan responsif.

Pengenalan

Nusa UI adalah framework CSS yang dibangun di atas Sass, dirancang untuk memberikan fleksibilitas maksimal dengan kode yang minimalis. Terinspirasi oleh Bootstrap 5, namun dengan pendekatan yang lebih ringan dan modern.

Fitur Utama

  • Ringan: Hanya menyertakan komponen esensial untuk performa optimal.
  • Modern: Dibangun dengan standar CSS terbaru (Flexbox, Grid, CSS Variables).
  • Tanpa jQuery: Menggunakan Vanilla JavaScript murni untuk interaksi komponen.
  • Sass: Mudah dikustomisasi melalui variabel dan mixin Sass.
