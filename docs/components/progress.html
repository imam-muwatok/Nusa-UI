Progress

Dokumentasi dan contoh untuk menggunakan progress bar kustom Nusa UI yang menampilkan indikator kemajuan.

Contoh

Progress bar dibangun dengan dua elemen HTML, beberapa CSS untuk mengatur lebar, dan beberapa atribut untuk aksesibilitas.

<div class="nusa-progress">
  <div class="nusa-progress-bar" role="progressbar" style="width: 25%" aria-valuenow="25" aria-valuemin="0" aria-valuemax="100"></div>
</div>

Labels

Tambahkan label ke dalam progress bar dengan menempatkan teks di dalam .nusa-progress-bar.

25%

Backgrounds

Gunakan kelas utilitas latar belakang untuk mengubah tampilan progress bar individu.

<div class="nusa-progress">
  <div class="nusa-progress-bar nusa-progress-bar-success" role="progressbar" style="width: 25%" aria-valuenow="25" aria-valuemin="0" aria-valuemax="100"></div>
</div>
