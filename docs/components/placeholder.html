Width

Anda dapat menggunakan kelas kolom grid, utilitas lebar, atau gaya inline untuk mengatur lebar placeholder.

Color

Secara default, placeholder menggunakan currentColor. Ini dapat ditimpa dengan kelas utilitas warna.

Sizing

Ukuran .nusa-placeholder didasarkan pada gaya tipografi elemen induk. Sesuaikan dengan pengubah ukuran: .nusa-placeholder-lg, .nusa-placeholder-sm, atau .nusa-placeholder-xs.

Animation

Animasikan placeholder dengan .nusa-placeholder-glow atau .nusa-placeholder-wave untuk mensimulasikan konten yang sedang dimuat secara aktif.
