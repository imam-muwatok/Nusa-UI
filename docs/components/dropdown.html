Dropdown

Toggle overlay kontekstual untuk menampilkan daftar tautan dan banyak lagi.

Contoh

Bungkus pemicu dropdown dan menu dropdown dalam .nusa-dropdown. Saat ini, dropdown diaktifkan saat hover (arahkan kursor).

  • Action
  • Another action
  • Something else here
<div class="nusa-dropdown">
  <button class="nusa-btn nusa-btn-primary" type="button">
    Dropdown button
  </button>
  <ul class="nusa-dropdown-menu">
    <li><a class="nusa-dropdown-item" href="#">Action</a></li>
    <li><a class="nusa-dropdown-item" href="#">Another action</a></li>
    <li><a class="nusa-dropdown-item" href="#">Something else here</a></li>
  </ul>
</div>
