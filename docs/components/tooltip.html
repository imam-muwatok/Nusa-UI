Four Directions

Arahkan kursor ke tombol di bawah ini untuk melihat empat arah tooltip: atas, kanan, bawah, dan kiri.

<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="tooltip" data-nusa-placement="top" title="Tooltip on top">
  Tooltip on top
</button>
<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="tooltip" data-nusa-placement="end" title="Tooltip on right">
  Tooltip on right
</button>
<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="tooltip" data-nusa-placement="bottom" title="Tooltip on bottom">
  Tooltip on bottom
</button>
<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="tooltip" data-nusa-placement="start" title="Tooltip on left">

</button>

HTML Content

Tooltip juga mendukung konten HTML (pastikan untuk membersihkan input pengguna jika menggunakan data dinamis).

<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="tooltip" data-nusa-html="true" title="<em>Tooltip</em> <u>with</u> <b>HTML</b>">
  Tooltip with HTML
</button>
