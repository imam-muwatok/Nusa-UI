Popover

Dokumentasi dan contoh untuk menambahkan popover, seperti yang ada di iOS, ke elemen apa pun di situs Anda.

Contoh

Klik tombol di bawah ini untuk mengaktifkan popover.

<button type="button" class="nusa-btn nusa-btn-lg nusa-btn-error" data-nusa-toggle="popover" title="Popover title" data-nusa-content="And here's some amazing content. It's very engaging. Right?">Click to toggle popover</button>

Four Directions

Empat opsi tersedia: top, right, bottom, dan left aligned.

<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="popover" data-nusa-placement="top" data-nusa-content="Top popover">
  Popover on top
</button>
<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="popover" data-nusa-placement="end" data-nusa-content="Right popover">
  Popover on right
</button>
<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="popover" data-nusa-placement="bottom" data-nusa-content="Bottom popover">
  Popover on bottom
</button>
<button type="button" class="nusa-btn nusa-btn-secondary" data-nusa-toggle="popover" data-nusa-placement="start" data-nusa-content="Left popover">
  Popover on left
</button>

Dismiss on Next Click

Gunakan pemicu focus untuk menutup popover pada klik berikutnya dari pengguna elemen yang berbeda dari elemen toggle.

Dismissible popover 
<a tabindex="0" class="nusa-btn nusa-btn-lg nusa-btn-error" role="button" data-nusa-toggle="popover" data-nusa-trigger="focus" title="Dismissible popover" data-nusa-content="And here's some amazing content. It's very engaging. Right?">Dismissible popover</a>
