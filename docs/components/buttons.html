Buttons

Gunakan gaya tombol kustom Nusa UI untuk tindakan dalam formulir, dialog, dan lainnya dengan dukungan untuk berbagai ukuran, status, dan lainnya.

Contoh

Nusa UI menyertakan beberapa gaya tombol yang telah ditentukan sebelumnya, masing-masing melayani tujuan semantiknya sendiri.

Outline buttons

Jika membutuhkan tombol, tetapi tidak ingin latar belakang yang berat, ganti kelas pengubah default dengan yang .nusa-btn-outline-*.

Sizes

Inginkan tombol yang lebih besar atau lebih kecil? Tambahkan .nusa-btn-lg, .nusa-btn-sm, atau ukuran lainnya.

Disabled State

Buat tombol terlihat tidak aktif dengan menambahkan atribut boolean disabled ke elemen <button>.

Block Buttons

Buat tombol tingkat blok—tombol yang membentang selebar penuh induknya—dengan menambahkan .nusa-btn-block.
