Modal

Gunakan plugin JavaScript modal Nusa UI untuk menambahkan dialog ke situs Anda untuk kotak cahaya, pemberitahuan pengguna, atau konten yang sepenuhnya kustom.

Contoh CSS-Only

Nusa UI mendukung modal berbasis CSS menggunakan pseudo-class :target. Ini memungkinkan modal berfungsi tanpa JavaScript untuk kasus penggunaan sederhana.

<!-- Trigger -->
<a href="#exampleModal" class="nusa-btn nusa-btn-primary">Launch demo modal</a>

<!-- Modal -->
<div id="exampleModal" class="nusa-modal">
  <div class="nusa-modal-dialog">
    <div class="nusa-modal-content">
      <div class="nusa-modal-header">
        <h5 class="nusa-modal-title">Modal title</h5>
        <a href="#" class="nusa-btn-close" aria-label="Close"></a>
      </div>
      <div class="nusa-modal-body">
        <p>Woohoo, you're reading this text in a modal!</p>
      </div>
      <div class="nusa-modal-footer">
        <a href="#" class="nusa-btn nusa-btn-secondary">Close</a>
        <button type="button" class="nusa-btn nusa-btn-primary">Save changes</button>
      </div>
    </div>
  </div>
</div>

Scrolling Long Content

Ketika modal menjadi terlalu panjang untuk viewport atau perangkat pengguna, mereka menggulir secara independen dari halaman itu sendiri.
