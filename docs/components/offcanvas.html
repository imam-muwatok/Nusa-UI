Offcanvas

Bangun sidebar tersembunyi ke dalam proyek Anda untuk navigasi, keranjang belanja, dan lainnya.

Cara Kerja

Offcanvas adalah komponen sidebar yang dapat di-toggle melalui JavaScript. Mirip dengan modal, tetapi muncul dari tepi viewport.

Contoh

Gunakan tombol di bawah ini untuk menampilkan dan menyembunyikan elemen offcanvas.

Placement

Tidak ada kelas penempatan default untuk komponen offcanvas, jadi Anda harus menambahkan salah satu kelas pengubah di bawah ini.

  • .nusa-offcanvas-start menempatkan offcanvas di sebelah kiri viewport.
  • .nusa-offcanvas-end menempatkan offcanvas di sebelah kanan viewport.
