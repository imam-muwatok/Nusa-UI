Accordion

Bangun accordion yang dapat dilipat secara vertikal dalam kombinasi dengan plugin Collapse kami.

Contoh

Klik accordion di bawah ini untuk memperluas/melipat konten accordion.

Accordion Item #1
Ini adalah item accordion pertama. Secara default item ini terbuka karena atribut open.
Accordion Item #2
Ini adalah item accordion kedua. Klik header untuk melihat isinya.
Accordion Item #3
Ini adalah item accordion ketiga. Konten tersembunyi secara default. 
<div class="nusa-accordion">
  <details class="nusa-accordion-item" open>
    <summary class="nusa-accordion-button">Accordion Item #1</summary>
    <div class="nusa-accordion-body">
      <strong>Ini adalah item accordion pertama.</strong> Secara default item ini terbuka karena atribut <code>open</code>.
    </div>
  </details>
  <details class="nusa-accordion-item">
    <summary class="nusa-accordion-button">Accordion Item #2</summary>
    <div class="nusa-accordion-body">
      Ini adalah item accordion kedua. Klik header untuk melihat isinya.
    </div>
  </details>
  <details class="nusa-accordion-item">
    <summary class="nusa-accordion-button">Accordion Item #3</summary>
    <div class="nusa-accordion-body">
      Ini adalah item accordion ketiga. Konten tersembunyi secara default.
    </div>
  </details>
</div>

Flush

Tambahkan .nusa-accordion-flush (belum diimplementasikan di CSS, ini hanya contoh struktur) untuk menghapus border luar dan sudut membulat.

Varian flush saat ini belum tersedia di CSS default, tetapi Anda dapat menambahkannya dengan mudah melalui Sass.
