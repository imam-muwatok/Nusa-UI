Sass

Manfaatkan kekuatan Sass untuk menyesuaikan Nusa UI agar sesuai dengan merek Anda.

Struktur File

Nusa UI dibangun dengan struktur modular. File utama adalah sass/nusa.scss yang mengimpor semua komponen.

sass/
├── abstracts/
│   ├── _functions.scss
│   ├── _mixins.scss
│   └── _variables.scss
├── base/
│   └── _reboot.scss
├── components/
│   ├── _buttons.scss
│   └── ...
├── utils/
│   ├── _grid.scss
│   └── ...
└── nusa.scss

Variabel

Setiap nilai CSS (warna, spasi, font) didefinisikan dalam sass/abstracts/_variables.scss. Anda dapat mengubah nilai-nilai ini sebelum mengompilasi.

Mengubah Warna Utama

// sass/abstracts/_variables.scss

$primary: #ff5722; // Ubah ke warna pilihan Anda
$border-radius: 0px; // Menghilangkan sudut melengkung

Kompilasi

Gunakan compiler Sass pilihan Anda atau script npm yang disediakan.

npm run watch
