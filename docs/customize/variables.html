Sass Variables

Kustomisasi Nusa UI dengan mudah dengan menimpa variabel Sass default kami.

Cara Menggunakan

Untuk menimpa variabel default, cukup definisikan ulang variabel tersebut di file Sass Anda sendiri sebelum mengimpor Nusa UI. Ini adalah cara yang disarankan untuk kustomisasi.

// 1. Definisikan ulang variabel kustom Anda
$primary: #A020F0; // Ungu
$border-radius: 0.5rem;

// 2. Impor file Sass Nusa UI
@import "path/to/nusa-ui/sass/nusa";

Daftar Variabel

Berikut adalah daftar beberapa variabel Sass global yang paling umum digunakan di Nusa UI.

Warna (Colors)

Variabel ini mengontrol palet warna dasar.

$primary:    #4745D5;
$secondary:  #E95897;
$accent:     #66D5BC;
$neutral:    #09090B;
$info:       #53BCFE;
$success:    #68D592;
$warning:    #F4B61A;
$error:      #EA5B7C;
$light:      #FFFFFF;
$dark:       #18181B;

Peta Warna (Color Maps)

Peta ini digunakan untuk menghasilkan kelas utilitas (misalnya .bg-primary, .text-error).

$theme-colors: (
  "primary":    $primary,
  "secondary":  $secondary,
  "accent":     $accent,
  "neutral":    $neutral,
  "info":       $info,
  "success":    $success,
  "warning":    $warning,
  "error":      $error,
  "light":      $light,
  "dark":       $dark
);

Spacing

Variabel $spacer adalah unit dasar untuk sebagian besar spasi. Peta $spacers digunakan untuk menghasilkan utilitas margin dan padding (misalnya .m-3, .p-1).

$spacer: 1rem;

$spacers: (
  0: 0,
  1: $spacer * .25,
  2: $spacer * .5,
  3: $spacer,
  4: $spacer * 1.5,
  5: $spacer * 3,
);

Tipografi (Typography)

Kontrol font dasar, ukuran, dan berat.

$font-family-base:      system-ui, -apple-system, "Segoe UI", Roboto, ...;
$font-size-base:        1rem;
$font-weight-base:      400;
$line-height-base:      1.5;
$body-color:            #18181B;
$body-bg:               #FFFFFF;

Border & Radius

Variabel untuk mengontrol border dan radius sudut elemen.

$border-width:          1px;
$border-color:          #dee2e6;
$border-radius:         0.375rem;
$border-radius-sm:      0.25rem;
$border-radius-lg:      0.5rem;

Grid Breakpoints

Tentukan titik henti responsif untuk sistem grid.

$grid-breakpoints: (
  xs: 0,
  sm: 576px,
  md: 768px,
  lg: 992px,
  xl: 1200px,
  xxl: 1400px
);
