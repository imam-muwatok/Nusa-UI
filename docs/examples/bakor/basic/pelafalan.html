Mengapa Bunyi Berubah?

Dalam bahasa Korea, bunyi huruf sering berubah tergantung pada huruf di sekitarnya. Tujuannya adalah untuk membuat pengucapan menjadi lebih mudah dan mengalir (flow). Klik pada kartu contoh untuk mendengarkan perbedaannya.

1. Liaison (Perangkaian)

Jika suku kata berakhir dengan konsonan (batchim) dan diikuti oleh vokal (huruf 'ㅇ'), bunyi konsonan tersebut pindah ke posisi 'ㅇ'.

한국어 → [한구거]
Han-guk-eo dibaca Han-gu-geo
🔊 Klik untuk dengar
할아버지 → [하라버지]
Hal-a-beo-ji dibaca Ha-ra-beo-ji
🔊 Klik untuk dengar

2. Nasalisasi (Sengau)

Ketika konsonan letup (seperti ㅂ, ㄷ, ㄱ) bertemu dengan konsonan hidung (ㄴ, ㅁ), bunyinya berubah menjadi sengau (ㅁ, ㄴ, ㅇ) agar lebih mudah diucapkan.

ㅂ bertemu ㄴ/ㅁ → [ㅁ]
합니다 → [함니다]
Hap-ni-da dibaca Ham-ni-da
🔊 Klik untuk dengar
ㄱ bertemu ㄴ/ㅁ → [ㅇ]
작년 → [장년]
Jak-nyeon dibaca Jang-nyeon
🔊 Klik untuk dengar

3. Aspirasi (Hembusan)

Ketika konsonan ㅎ bertemu dengan ㄱ, ㄷ, ㅂ, atau ㅈ, kedua huruf tersebut bergabung menjadi konsonan aspirasi yang kuat (ㅋ, ㅌ, ㅍ, ㅊ).

ㄱ + ㅎ → [ㅋ]
축하 → [추카]
Chuk-ha dibaca Chu-ka
🔊 Klik untuk dengar
ㅎ + ㄷ → [ㅌ]
좋다 → [조타]
Joh-da dibaca Jo-ta
🔊 Klik untuk dengar

4. Tensification (Pengerasan)

Konsonan biasa (ㄱ, ㄷ, ㅂ, ㅅ, ㅈ) diucapkan menjadi konsonan rangkap (ㄲ, ㄸ, ㅃ, ㅆ, ㅉ) setelah batchim tertentu.

ㄱ + ㄱ → [ㄲ]
학교 → [학꾜]
Hak-gyo dibaca Hak-kkyo
🔊 Klik untuk dengar
ㄱ + ㅅ → [ㅆ]
학생 → [학쌩]
Hak-saeng dibaca Hak-ssaeng
🔊 Klik untuk dengar

5. Palatalization (Palatalisasi)

Jika batchim ㄷ atau ㅌ bertemu dengan vokal '이', bunyinya berubah menjadi '지' atau '치'.

ㅌ + 이 → [치]
같이 → [가치]
Gat-i dibaca Ga-chi
🔊 Klik untuk dengar
ㄷ + 이 → [지]
굳이 → [구지]
Gud-i dibaca Gu-ji
🔊 Klik untuk dengar

6. Liquidation (Likuida)

Ketika ㄴ bertemu dengan ㄹ (atau sebaliknya), bunyi ㄴ berubah menjadi ㄹ.

ㄴ + ㄹ → [ㄹㄹ]
신라 → [실라]
Sin-la dibaca Sil-la
🔊 Klik untuk dengar
ㄹ + ㄴ → [ㄹㄹ]
설날 → [설랄]
Seol-nal dibaca Seol-lal
🔊 Klik untuk dengar

7. Cluster Simplification (Penyederhanaan Gugus)

Jika batchim terdiri dari dua konsonan dan diikuti konsonan lain atau akhir kata, hanya satu yang diucapkan.

ㄺ → [ㄱ]
닭 → [닥]
Dalg dibaca Dak
🔊 Klik untuk dengar
ㅄ → [ㅂ]
없다 → [업따]
Eobs-da dibaca Eop-tta
🔊 Klik untuk dengar

8. H-Deletion (Penghilangan H)

Huruf ㅎ seringkali menjadi lemah atau hilang sama sekali jika berada di antara bunyi bersuara (vokal, ㄴ, ㄹ, ㅁ, ㅇ).

ㅎ hilang antar vokal
좋아요 → [조아요]
Joh-a-yo dibaca Jo-a-yo
🔊 Klik untuk dengar
ㄴ + ㅎ → [ㄴ]
은행 → [으냉]
Eun-haeng dibaca Eu-naeng
🔊 Klik untuk dengar
