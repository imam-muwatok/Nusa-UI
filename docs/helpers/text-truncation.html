Text truncation

Potong string teks yang cukup panjang dengan elipsis.

Contoh

Untuk memotong teks yang panjang, Anda dapat menggunakan kelas .text-truncate. Kelas ini memerlukan display: inline-block atau display: block agar berfungsi dengan benar.

Praeterea iter est quasdam res quas ex communi.
Praeterea iter est quasdam res quas ex communi. 
<!-- Block level -->
<div class="nusa-row">
  <div class="nusa-col-2 text-truncate">
    Praeterea iter est quasdam res quas ex communi.
  </div>
</div>

<!-- Inline level -->
<span class="d-inline-block text-truncate" style="max-width: 150px;">
  Praeterea iter est quasdam res quas ex communi.
</span>
