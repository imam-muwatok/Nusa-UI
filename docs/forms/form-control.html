Form Control

Berikan gaya pada kontrol formulir tekstual dengan dukungan untuk berbagai jenis input, textarea, dan status.

Contoh

Gunakan .nusa-form-control pada elemen <input> dan <textarea>.

Disabled

Tambahkan atribut disabled pada input untuk mencegah interaksi pengguna.

Readonly

Tambahkan atribut readonly pada input untuk mencegah modifikasi nilai.

File Input

Input file juga menggunakan kelas .nusa-form-control.
