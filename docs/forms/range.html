Range

Gunakan input range kustom kami untuk gaya lintas-browser yang konsisten dan kustomisasi bawaan.

Overview

Buat kontrol <input type="range"> kustom dengan .nusa-form-range. Track (latar belakang) dan thumb (pegangan) keduanya diberi gaya agar muncul sama di seluruh browser.

<label for="customRange1" class="nusa-form-label">Example range</label>
<input type="range" class="nusa-form-range" id="customRange1">

Min and Max

Input range memiliki nilai implisit untuk min dan max—0 dan 100, masing-masing. Anda dapat menentukan nilai baru untuk atribut tersebut.

Disabled

Tambahkan atribut disabled boolean pada input untuk memberinya tampilan abu-abu dan menghapus kejadian pointer.
