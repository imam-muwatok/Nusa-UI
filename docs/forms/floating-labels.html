Floating Labels

Buat label formulir yang mengapung di atas kolom input Anda.

Contoh

Bungkus sepasang <input class="nusa-form-control"> dan <label> di dalam .nusa-form-floating untuk mengaktifkan label mengambang dengan input tekstual.

Textareas

Secara default, <textarea> dengan label mengambang akan memiliki ketinggian yang sama dengan <input>.

Untuk mengatur ketinggian kustom pada textarea Anda, jangan gunakan atribut rows. Sebagai gantinya, atur height eksplisit (baik inline atau melalui CSS kustom).

Selects

Selain .nusa-form-control, label mengambang juga tersedia untuk .nusa-form-select.

Layout

Saat bekerja dengan sistem grid Nusa UI, pastikan untuk menempatkan elemen formulir dalam kolom kolom.
