Breakpoints

Breakpoints adalah blok bangunan dasar dari tata letak responsif. Gunakan mereka untuk mengontrol kapan tata letak Anda dapat beradaptasi di seluruh viewport atau ukuran perangkat.

Cara Kerja Breakpoints

Nusa UI menggunakan pendekatan mobile-first untuk pengembangan responsif. Ini berarti kode untuk tata letak seluler adalah default, dan gaya kemudian ditimpa untuk rentang breakpoint yang lebih besar.

Breakpoints ditentukan dalam Sass dan dapat disesuaikan. Berikut adalah breakpoint default:

// sass/abstracts/_variables.scss

$grid-breakpoints: (
  xs: 0,    // Extra small devices (portrait phones)
  sm: 576px, // Small devices (landscape phones)
  md: 768px, // Medium devices (tablets)
  lg: 992px, // Large devices (desktops)
  xl: 1200px, // Extra large devices (large desktops)
  xxl: 1400px // Extra extra large devices (larger desktops)
);

Penggunaan dalam Kelas Utilitas

Breakpoints digunakan dalam kelas utilitas responsif seperti .d-md-flex, .col-lg-6, atau .text-sm-center. Ini memungkinkan Anda untuk menerapkan gaya yang berbeda berdasarkan ukuran layar.
