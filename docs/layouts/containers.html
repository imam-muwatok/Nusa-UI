Containers

Container adalah elemen tata letak paling dasar di Nusa UI dan diperlukan saat menggunakan sistem grid default kami.

Container Default

Kelas .nusa-container (atau .ns-container) menetapkan max-width pada setiap breakpoint responsif. Ini membuat konten Anda terpusat dan memiliki padding horizontal.

<div class="nusa-container">
  <!-- Konten Anda di sini -->
</div>
Ini adalah contoh .nusa-container

Container Fluid

Gunakan .nusa-container-fluid (atau .ns-container-fluid) untuk container dengan lebar penuh, yang mencakup seluruh lebar viewport.

<div class="nusa-container-fluid">
  <!-- Konten Anda di sini -->
</div>
Ini adalah contoh .nusa-container-fluid
