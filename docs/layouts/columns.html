Reordering

Gunakan kelas .order- untuk mengontrol urutan visual konten Anda.

First in DOM, ordered last
Second in DOM, unordered
Third in DOM, ordered first
<div class="nusa-container">
  <div class="nusa-row">
    <div class="nusa-col order-last">First in DOM, ordered last</div>
    <div class="nusa-col">Second in DOM, unordered</div>
    <div class="nusa-col order-first">Third in DOM, ordered first</div>
  </div>
</div>
