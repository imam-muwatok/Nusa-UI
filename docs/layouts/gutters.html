Gutters

Gutters adalah jarak antar kolom, yang dibuat menggunakan padding horizontal. Kami menggunakan padding pada setiap kolom dan margin negatif pada baris untuk menyelaraskan konten.

Cara Kerja

  • Padding Kolom: Gutters dibuat dengan padding horizontal pada setiap kolom (.nusa-col-*).
  • Margin Baris: .nusa-row memiliki margin negatif horizontal untuk menetralkan padding pada kolom awal dan akhir.
  • Overflow: Karena margin negatif, konten mungkin meluap dari container jika tidak ditangani dengan benar (biasanya .nusa-container menangani ini dengan padding).

Default Gutter

Secara default, Nusa UI menggunakan gutter dengan lebar tertentu (biasanya 1.5rem atau 24px total, 12px di setiap sisi kolom).

Kustomisasi dengan Sass

Anda dapat mengubah lebar gutter dengan mengubah variabel $grid-gutter-width di file _variables.scss.

// sass/abstracts/_variables.scss

$grid-gutter-width: 2rem; // Ubah sesuai kebutuhan
