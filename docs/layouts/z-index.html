Z-index

Gunakan utilitas z-index kami untuk mengontrol tumpukan elemen pada sumbu Z.

Contoh

Kelas .z-{value} tersedia untuk nilai 0 hingga 3, serta n1 untuk -1.

z-3
z-2
z-1
z-0
z-n1
<div class="z-3 position-absolute p-5 rounded-3 bg-primary"></div>
<div class="z-2 position-absolute p-5 rounded-3 bg-secondary"></div>
<div class="z-1 position-absolute p-5 rounded-3 bg-success"></div>
<div class="z-0 position-absolute p-5 rounded-3 bg-warning"></div>
<div class="z-n1 position-absolute p-5 rounded-3 bg-dark"></div>

Catatan: Properti z-index hanya berfungsi pada elemen yang memiliki position (seperti absolute, relative, fixed, atau sticky) dan flex items.
