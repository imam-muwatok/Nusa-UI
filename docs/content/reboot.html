Reboot

Reboot, kumpulan perubahan CSS khusus elemen, memulai Nusa UI untuk menyediakan dasar yang elegan, konsisten, dan sederhana untuk dibangun.

Pendekatan

Reboot dibangun di atas Normalize.css, menyediakan banyak elemen HTML dengan gaya yang agak beropini menggunakan hanya pemilih elemen. Penataan tambahan dilakukan hanya melalui kelas. Misalnya, kami me-reboot beberapa elemen <table> untuk baseline yang lebih sederhana dan kemudian menyediakan .nusa-table, .nusa-table-bordered, dan lainnya.

Default Halaman

Elemen <html> dan <body> diperbarui untuk memberikan default halaman yang lebih baik. Lebih khusus lagi:

  • box-sizing diatur secara global pada setiap elemen—termasuk *::before dan *::after, ke border-box. Ini memastikan bahwa lebar elemen yang dideklarasikan tidak pernah terlampaui karena padding atau border.
  • Tidak ada font-size dasar yang dideklarasikan pada <html>, tetapi 16px diasumsikan (default browser). font-size: 1rem diterapkan pada <body> untuk penskalaan tipe responsif yang mudah melalui kueri media sambil menghormati preferensi pengguna dan memastikan pendekatan yang lebih mudah diakses.
  • <body> juga menetapkan font-family global, line-height, dan text-align. Ini diwarisi nanti oleh beberapa elemen formulir untuk mencegah inkonsistensi font.
  • Demi keamanan, <body> memiliki background-color yang dideklarasikan, defaultnya adalah #fff.

Native Font Stack

Font web default (Helvetica Neue, Helvetica, dan Arial) telah dihapus di Nusa UI dan diganti dengan "native font stack" untuk rendering teks yang optimal di setiap perangkat dan OS.

$font-family-sans-serif: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", "Liberation Sans", sans-serif, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji";

Headings dan Paragraf

Semua elemen heading—misalnya, <h1>—dan <p> diatur ulang agar margin-top mereka dihapus. Heading memiliki margin-bottom: .5rem ditambahkan dan paragraf margin-bottom: 1rem untuk spasi yang mudah.
