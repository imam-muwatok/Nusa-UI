Figures

Dokumentasi dan contoh untuk menampilkan gambar terkait dan teks dengan elemen figure.

Basic Usage

Gunakan elemen <figure> untuk membungkus gambar dan <figcaption> untuk keterangan gambar. Anda dapat menggunakan kelas utilitas Nusa UI seperti .rounded, .mb-2, dan .text-gray-600 untuk penataan.

<figure class="d-inline-block">
  <img src="..." class="rounded mb-2" alt="...">
  <figcaption class="small text-gray-600">Keterangan untuk gambar di atas.</figcaption>
</figure>

Aligning Figure

Menyejajarkan figure dengan mudah menggunakan utilitas teks alignment.

<figure class="text-center">
  <img src="..." class="rounded mb-2" alt="...">
  <figcaption class="small text-gray-600">Keterangan di tengah.</figcaption>
</figure>
<figure class="text-end">
  <img src="..." class="rounded mb-2" alt="...">
  <figcaption class="small text-gray-600">Keterangan di kanan.</figcaption>
</figure>
